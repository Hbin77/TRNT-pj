# 소셜 로그인 설정 가이드 (Social Login Setup Guide)

이 문서는 TRNT 프로젝트의 소셜 로그인(카카오, 구글) 기능을 활성화하기 위해 필요한 API 키 발급 및 설정 방법을 설명합니다.

---

## 1. 카카오 로그인 (Kakao Login)

### 1단계: 애플리케이션 생성
1. **[Kakao Developers](https://developers.kakao.com/)** 접속 및 로그인.
2. 메인 화면의 **[내 애플리케이션]** > **[애플리케이션 추가하기]** 클릭.
3. 앱 이름(예: `TRNT`), 사업자명(본인 이름) 입력 후 저장.

### 2단계: 키 확인 (`.env` 설정)
1. 생성된 앱의 **[요약 정보]** 메뉴로 이동.
2. **REST API 키**를 복사합니다.
   - 이것이 `KAKAO_CLIENT_ID`입니다.
3. (선택) **[제품 설정]** > **[카카오 로그인]** > **[보안]**에서 Client Secret을 생성했다면 복사합니다.
   - 이것이 `KAKAO_CLIENT_SECRET`입니다. (설정 안 했으면 공란 가능)

### 3단계: 플랫폼 및 리다이렉트 URI 설정
1. **[플랫폼]** 메뉴 > **Web 플랫폼 등록** 클릭.
   - 사이트 도메인: `http://localhost:3000` (개발용), `https://your-domain.com` (배포용) 입력.
2. **[카카오 로그인]** 메뉴로 이동.
   - **활성화 설정(OFF -> ON)** 변경.
   - **Redirect URI 등록** 버튼 클릭 후 아래 주소 입력:
     ```
     http://localhost:8000/api/v1/auth/kakao/callback
     ```

### 4단계: 동의 항목 설정
1. **[카카오 로그인]** > **[동의항목]** 메뉴로 이동.
2. **닉네임**, **이메일(필수 권장)** 항목을 '사용함' 또는 '필수 동의'로 설정.

---

## 2. 구글 로그인 (Google Login)

### 1단계: 프로젝트 생성
1. **[Google Cloud Console](https://console.cloud.google.com/)** 접속 및 로그인.
2. 좌측 상단 프로젝트 선택 > **[새 프로젝트]** 클릭.
3. 프로젝트 이름(예: `TRNT`) 입력 후 만들기.

### 2단계: OAuth 동의 화면 구성
1. 좌측 메뉴 **[API 및 서비스]** > **[OAuth 동의 화면]** 이동.
2. User Type: **외부(External)** 선택 후 만들기.
3. **앱 정보 입력**:
   - 앱 이름: `TRNT`
   - 사용자 지원 이메일: 본인 이메일
   - 개발자 연락처 정보: 본인 이메일
4. 저장 후 계속 진행 (범위/Scope 설정은 `email`, `profile`, `openid` 기본 선택).
5. **테스트 사용자**: 개발 단계에서는 본인 구글 이메일을 추가해야 로그인이 가능합니다.

### 3단계: 사용자 인증 정보 만들기
1. 좌측 메뉴 **[API 및 서비스]** > **[사용자 인증 정보]** 이동.
2. 상단 **[+ 사용자 인증 정보 만들기]** > **[OAuth 클라이언트 ID]** 선택.
3. 애플리케이션 유형: **웹 애플리케이션**.
4. 이름: `TRNT Web Client`.
5. **승인된 자바스크립트 원본**:
   - `http://localhost:3000`
   - `http://localhost:8000`
6. **승인된 리디렉션 URI** (가장 중요!):
   - 아래 주소를 정확히 입력하고 엔터/추가:
     ```
     http://localhost:8000/api/v1/auth/google/callback
     ```
7. **만들기** 버튼 클릭.

### 4단계: 키 확인 (`.env` 설정)
1. 생성 완료 팝업에서 **클라이언트 ID**와 **클라이언트 보안 비밀(Secret)**을 확인합니다.
2. 각각 `.env` 파일의 다음 항목에 입력합니다:
   - `GOOGLE_CLIENT_ID`
   - `GOOGLE_CLIENT_SECRET`

---

## 3. 리다이렉트 URI 요약 (개발 환경)

설정 시 아래 URI가 각 플랫폼 개발자 센터에 정확히 등록되어 있어야 합니다.

| 플랫폼 | 설정 위치 | Redirect URI |
|---|---|---|
| **Kakao** | 카카오 로그인 > Redirect URI | `http://localhost:8000/api/v1/auth/kakao/callback` |
| **Google** | 사용자 인증 정보 > 승인된 리디렉션 URI | `http://localhost:8000/api/v1/auth/google/callback` |

---

모든 설정 후에는 **백엔드 서버를 재시작**해야 `.env` 변경 사항이 적용됩니다.
