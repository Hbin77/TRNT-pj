# TRNT Frontend

> 평행세계 인생 시뮬레이터 프론트엔드

## 🚀 시작하기

\`\`\`bash
npm install
npm run dev
\`\`\`

http://localhost:3000

## 🛠️ 기술 스택

- Next.js 14 + TypeScript
- Tailwind CSS
- Zustand (상태 관리)
- Axios (API)
- React Hook Form

## 주요 페이지

- `/` - 랜딩 페이지
- `/login` - 로그인  
- `/register` - 회원가입
- `/dashboard` - 대시보드
